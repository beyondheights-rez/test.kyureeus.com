# Custom Fonts Directory

Place your custom local font files in this folder. 

## Supported Formats
It is highly recommended to use **`.woff2`** format for web performance, but you can also use `.woff`, `.ttf`, or `.otf`.

## Recommended File Names
By default, the font configuration in [fonts.ts](file:///c:/Users/MuralidharanSubraman/Documents/kyureeus%20website/src/app/fonts.ts) looks for the following file names:

### Sans-Serif Font (e.g. Satoshi, Cabinet Grotesk, etc.)
- `CustomSans-Regular.woff2` (for regular weight: 400)
- `CustomSans-Bold.woff2` (for bold weight: 700)

### Serif Font (e.g. Lora, Ogg, Editorial New, etc.)
- `CustomSerif-Regular.woff2` (for regular weight: 400)
- `CustomSerif-Bold.woff2` (for bold weight: 700)

## Modifying Names and Paths
If you choose to use different font names, formats, or add more weights/styles, you can update the configuration directly in [fonts.ts](file:///c:/Users/MuralidharanSubraman/Documents/kyureeus%20website/src/app/fonts.ts).
